04 · Macros VBA

            
📄
ExporterPDF()Vérifie la journée choisie et exporte le tableau de bord en PDF avec un nom explicite.

            
🎤
ListeConcerts()Boucle sur les 180 concerts et recopie ceux du jour dans la feuille Programmation.

            
🛡️
AfficherProgrammation()Gère les cas d'erreur : aucune date choisie, aucun concert ce jour-là.

            
⟳
ActualiserTableauDeBord()Force le recalcul complet du classeur depuis un bouton.

          


Sub ExporterPDF()
    Dim jour As String
    Dim chemin As String

    jour = Sheets("TABLEAU DE BORD — FESTIVAL 2026") _
           .Range("C3").Value

    If jour = "" Then
        MsgBox "Veuillez sélectionner un jour."
        Exit Sub
    End If

    chemin = ThisWorkbook.Path & "\Festival_" & jour & ".pdf"

    Sheets("TABLEAU DE BORD — FESTIVAL 2026") _
        .ExportAsFixedFormat Type:=xlTypePDF, _
        Filename:=chemin, OpenAfterPublish:=True
End Sub
